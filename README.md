# ゴルフ上達アプリ（自分専用）

iPhone のホーム画面に追加して使う、自分専用のゴルフアプリです。
データはすべてスマホの中に保存し、月額料金やAIのサービスは一切使いません。

- 公開サイト: https://wata98.github.io/golf-app/
- コードの置き場所: https://github.com/wata98/golf-app

---

## このアプリでできること

| タブ | できること |
|---|---|
| ラウンド前 | **練習メニュー**（弱点に合わせて球数つきで作る・手応えを記録）／**ドリル集**（40個・追加や編集もできる）／**飛距離を記録**（クラブごと）／**攻略プラン**（ホールごとのハザード登録と、ティーショットのクラブ・狙いの提案）／**空き確認**（楽天GORAの空き一覧、1人予約を各サイトで開く） |
| ラウンド中 | **スコア入力**（打数・パット・ティーショットなどを大きいボタンで）／**番手早見表**／ホールごとの**攻略プラン**の表示／**グリーン中央までの距離**（GPS） |
| 振り返り | **ラウンド**の一覧と詳細／**飛距離**の集計とグラフ／**分析**（一番の課題と理由、失点の内訳、指標の推移）／**練習**の回数と内訳／**スイング**動画の解析（骨格の線・数値・比較） |
| 設定 | 目標スコア、練習の配分、マイクラブ、早見表の補正、楽天のキー、利き手・身長、**バックアップの保存と復元** |

空き確認（ネットが必要）と、スイング解析の初回（部品の読み込み）以外は、圏外でも動きます。

## パソコンで動作を確認する

### 必要なもの（どれも無料・入れてあります）
| ソフト | 何に使うか | 入っていないとき |
|---|---|---|
| Python | パソコンでアプリを開く | https://www.python.org/ から入れる |
| Node.js | 自動テストを動かす | https://nodejs.org/ から「LTS」を入れる |
| Git | GitHub に送る（公開を更新する） | https://git-scm.com/ から入れる |

### アプリを開く
1. エクスプローラーで `golf-app` フォルダを開く
2. **`start-local.bat` をダブルクリック**する
3. ブラウザで http://localhost:8000 が開く（開かないときはアドレス欄に入れる）
4. 終わるときは、黒いウィンドウを閉じる

コマンドで開くときは、PowerShell で:

```powershell
cd "$env:USERPROFILE\OneDrive\Desktop\golf-app"
```

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" -m http.server 8000 --bind 127.0.0.1
```

注意:
- パソコンのブラウザのデータは、iPhone のデータとは別です（試しに入れたデータは iPhone に出ません）
- 空き確認（楽天）は、パソコン（localhost）からはつながりません。公開サイトで試してください
- `index.html` を直接ダブルクリックして開くと動きません（必ず上の方法で開く）

### 自動テストを動かす
直したあとは必ずテストを通します。**`run-tests.bat` をダブルクリック**し、最後に「すべてのテストが通りました」と出ればOKです。

コマンドで動かすときは:

```powershell
cd "$env:USERPROFILE\OneDrive\Desktop\golf-app"
```

```powershell
& "C:\Program Files\nodejs\node.exe" --test
```

最後に `fail 0` と出れば全部通っています。✖ の付いた行が、通らなかったテストです。

## 公開サイトを更新する（直したものを iPhone に届ける）

1. **版の番号を上げる**（上げないと iPhone に古い版が残ります）
   - `js/version.js` の `APP_VERSION` と、`sw.js` の `APP_VERSION` を**同じ番号**にする（例: `0.8.1` → `0.8.2`）
   - 機能を足したら真ん中（`0.9.0`）、直しだけなら最後（`0.8.2`）
2. **テストを通す**（上の「自動テストを動かす」）
3. **GitHub に送る**（PowerShell で、1行ずつ）:

```powershell
cd "$env:USERPROFILE\OneDrive\Desktop\golf-app"
```

```powershell
git add -A
```

```powershell
git commit -m "ここに直した内容を日本語で書く"
```

```powershell
git push
```

4. 1〜2分待ってから、公開サイトの版を確かめる（ブラウザで開くと、新しい番号が書いてあればOK）:
   https://wata98.github.io/golf-app/js/version.js
5. iPhone でアプリを完全に閉じて開き直し、「設定」の一番下の版が新しい番号になっているか見る

初めて `git push` するパソコンでは、GitHub のログイン画面が出ます。自分でログインしてください。

## バックアップと復元

### バックアップを保存する（月に1回はやる）
1. アプリの「設定」→「**バックアップを保存**」
2. 共有の画面で「"ファイル"に保存」→ **iCloud Drive** を選んで保存
   - 「もう一度押してください」と出たら、もう一度「バックアップを保存」を押す（スイングの静止画が多いと準備に時間がかかるため）
3. 最後のバックアップから30日たつと、アプリの上に黄色いお知らせが出ます

バックアップに入るもの: ラウンド、飛距離、クラブ、ゴルフ場と攻略プラン、練習、ドリル集、スイングの静止画と数値、設定。
入らないもの: **楽天のアプリID・アクセスキー**（他人に知られてはいけないため）。

### 復元する
1. 「設定」→「**バックアップから復元**」→ 保存したファイルを選ぶ
2. 「今のデータをすべて置き換えます」の確認で「置き換える」
   - 今のデータは置き換わります（直前の状態はアプリの中に自動で控えますが、画面から戻す機能はありません）

### iPhone を機種変更するとき
1. **古い iPhone** で「バックアップを保存」→ iCloud Drive に保存
2. **新しい iPhone** の Safari で https://wata98.github.io/golf-app/ を開く
3. 共有ボタン →「**ホーム画面に追加**」→ ホーム画面のアイコンから開く（以後は必ずアイコンから）
4. 「設定」→「バックアップから復元」→ iCloud Drive のファイルを選ぶ
5. 「設定」→「楽天GORAの空き確認」で、アプリID・アクセスキーを**入れ直す**（楽天ウェブサービスのサイトで確認できます）
6. スイング解析を初めて使うときは、電波のある所で（部品約25MBを読み込み直します）
7. GPS（グリーンまでの距離）は、位置情報の許可を聞かれたら「許可」

### データが消えるとき（気をつけること）
- ホーム画面のアイコンを削除すると、データも消えます
- Safari で開いたときと、ホーム画面から開いたときは、保存場所が別です
- 設定アプリで「履歴とWebサイトデータを消去」をすると消えることがあります

## 楽天GORAの空き確認を使う準備
1. https://webservice.rakuten.co.jp/ に楽天IDでログインし、アプリを作る
   - Application URL: `https://wata98.github.io/golf-app/`
   - Allowed websites（許可するWebサイト）: `wata98.github.io`
2. 表示された **Application ID** と **Access Key** を、アプリの「設定」→「楽天GORAの空き確認」に貼り付け →「保存する」→「接続を試す」
3. 2つのキーは他人に見せない（楽天の規約で決まっています。GitHub にも書かない）

## 1人予約スクリプトについて
**作っていません。** 楽天GORA・GDO・じゃらんゴルフには1人予約の情報を取る公式の仕組み（API）がなく、
画面をプログラムで読むことは各サイトの規約に反するおそれがあるためです（調査結果: `docs/research-availability.md`）。
代わりに、アプリの「空き確認」に、**条件を入れた状態で各サイトの1人予約検索を開くボタン**があります。
