承認を受けて、CLAUDE.md の「技術」「コマンド」と `docs/data-model.md` に正式に書いた。

## 1. 使う技術と理由

| 何に | 使うもの | 理由 |
|---|---|---|
| 画面と処理 | 素のHTML・CSS・JavaScript（フレームワークなし） | 変換作業（ビルド）が要らず、ファイルをそのまま公開できる。無料版Claudeにファイルを貼れば直せる。流行りの道具が廃れても動き続ける |
| ファイルの分け方 | JavaScriptの「モジュール」（ファイルごとに部品を分ける標準の仕組み） | 機能ごとのフォルダに短いファイルで分けられる |
| データ保存 | IndexedDB（ブラウザに最初からある保存場所） | 動画も保存できる。外部サービス不要 |
| オフライン | Service Worker（ブラウザ標準。アプリのファイルをスマホに保存しておく仕組み）を自分で書く | 圏外のゴルフ場でも開ける |
| グラフ | Chart.js（有名で10年以上続くグラフ用ライブラリ）を1ファイルだけ同梱 | 弱点分析・飛距離推移のグラフを短いコードで描ける。ネットから読まずに同梱するのでオフラインで動く |
| 骨格推定（機能7の後半） | MediaPipe（Google製・無料）を同梱 | スマホの中で動き、動画を外に送らない。手動解析の段階では入れない |
| テスト | Node.js（パソコンに入れる無料のソフト）に最初から付いているテスト機能 | テスト用のライブラリを追加せずに済む。**今このパソコンにNode.jsは入っていないので、最初の依頼のときに入れ方を案内する** |
| 公開 | GitHub Pages | 無料。pushするだけで更新される |

使わないもの: React・Vue などのフレームワーク、ビルドツール、外部データベース、ログイン、AIのAPI。

## 2. データの形（7機能すべてを見越して）

保存場所（IndexedDBの「棚」）を分け、全部に共通で `id`・`createdAt`（作成日時）・`updatedAt`（更新日時）を持たせる。
距離はヤード、日付は `2026-11-09` の形。

| 棚 | 中身 | 使う機能 |
|---|---|---|
| `meta` | データのバージョン番号、最後にJSONを書き出した日 | 全部（移行・バックアップのお知らせ） |
| `settings` | 表示の好み、楽天のアプリID（機能6、入力したときだけ） | 全部 |
| `clubs` | クラブ（名前「7I」、種類、ロフト、バッグに入っているか、並び順） | 1・2・5・7 |
| `distanceRecords` | 飛距離の記録（クラブ、日付、キャリー、ランを含めた距離、どこで測ったか: 練習場/ラウンド/計測器） | 2・5 |
| `courses` | ゴルフ場（名前、県、ティーごとの18ホールのパー・距離、楽天GORAのゴルフ場番号、予約サイトのリンク、お気に入り） | 1・5・6 |
| `holeNotes` | ホール攻略メモ（ゴルフ場、ホール番号、メモ、ティーショットの番手、狙う方向） | 5 |
| `rounds` | ラウンド（日付、ゴルフ場、ティー、天気、記録中/完了、ホールごとの打数・パット数・フェアウェイ（当たり/左/右）・パーオン・ペナルティ・バンカー） | 1・3・4 |
| `shots` | 1打ごとの記録（ラウンド、ホール、何打目、クラブ、ライ、結果: ナイス/左/右/ショート/オーバー/OB/池、残り距離） | 1・2・3・5 |
| `practiceSessions` | 練習した記録（日付、提案されたメニュー、やった項目、球数、メモ） | 4 |
| `swingVideos` | スイング動画（動画本体、日付、クラブ、撮った向き、描いた線や角度とそのコマ、メモ、あとで自動計測の結果） | 7 |
| `availabilitySearches` | 空き確認でよく使う条件（ゴルフ場、曜日、時間帯） | 6 |

設計の考え方:
- **打数はホールの合計を正とし、1打ごとの記録は任意**。急いでいるときは「5打・2パット」だけでも記録でき、余裕があれば1打ずつ記録すると弱点分析が細かくなる
- 分析（平均スコア・パーオン率・クラブごとの平均飛距離など）は保存せず、毎回記録から計算する。計算結果の食い違いが起きない
- クラブやゴルフ場は `id` で結びつける。名前を変えても過去の記録が壊れない。クラブを手放しても消さずに「バッグから外す」にする
- バージョン番号を持たせ、形を変えるときは「v1→v2」のような移行処理を1つずつ足す。移行の前に自動でバックアップを1つ取る
- **JSON書き出しに動画本体を入れるかは要相談**: 動画は大きいので、JSONには動画の情報（線・角度・メモ）だけを入れ、動画はiPhoneの写真アプリに元ファイルを残しておく形を提案する

## 3. iPhoneでPWAを使うときの注意点

データが消える・見えなくなる条件:
- **ホーム画面のアイコンを削除すると、そのアプリのデータも消える**。消す前に必ずJSONを書き出す
- **Safariで開いたときと、ホーム画面から開いたときは保存場所が別**。Safariで入力したデータはホーム画面アプリには出てこない。使うのは必ずホーム画面から
- Safariで開いたままのサイトは、7日間使わないとデータが消されることがある（ホーム画面アプリはこの対象外）
- 「設定 → アプリ → Safari → 履歴とWebサイトデータを消去」をすると消える可能性がある
- iPhoneの空き容量が極端に少ないと消される可能性がある。動画をたくさん保存すると容量を使う
- 機種変更ではデータは引き継がれない。JSONを書き出して新しいiPhoneで読み込む

対策としてアプリに入れること:
- 「データを消されにくくしてください」とブラウザに頼む仕組み（`navigator.storage.persist`）を使う
- 最後の書き出しから30日たったら「JSONを書き出してください」と表示する
- 書き出したJSONは「ファイル」アプリのiCloud Driveに保存すると、iPhoneをなくしても残る

その他:
- ホーム画面への追加は、Safariで開いて「共有」→「ホーム画面に追加」
- オフラインで使うには、一度ネットがある所で開いておく必要がある
- アプリを更新しても、すぐには新しい版にならないことがある（閉じて開き直すと変わる）。画面に版番号を表示する
- ラウンド中に画面が消えないようにする機能は、古いiOSでは効かないことがある
- 普通のゴルフ手袋では画面が反応しにくい。指先がスマホ対応の手袋か、手袋を外した手で押す前提でボタンを大きくする
