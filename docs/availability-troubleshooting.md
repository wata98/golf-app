# 空き確認（機能6）が動かなくなったときの直し方

空き確認は、ほかの会社のサービス（楽天のAPI、楽天GORA・GDOの検索ページ）に頼っているので、
相手の仕様が変わると動かなくなる。直すときは、無料版のClaudeにこのファイルと該当するファイルを貼って相談するとよい。

## まず、どこが壊れたかを見分ける
| 画面に出ること | 壊れた場所 | 見るファイル |
|---|---|---|
| 「楽天に断られました」「アプリIDかアクセスキーが正しくありません」 | 楽天のキー・設定 | 下の「A」 |
| 「許可するWebサイト…の登録が合っていません」 | 楽天のアプリ設定 | 下の「A」 |
| 「メンテナンス中か混み合っています」がずっと続く | 楽天側、または開いている住所 | 下の「B」 |
| 「楽天のAPIの接続先が見つかりません（404）」 | 楽天のAPIの住所・版が変わった | 下の「C」 |
| 「楽天の返事の形が変わったようです（〇〇がありません）」 | 楽天の返事の形が変わった | 下の「D」 |
| 「楽天につながりませんでした」（電波はある） | 住所が変わった、または楽天がブラウザからの呼び出しをやめた | 下の「C」「E」 |
| 「〇〇の1人予約で開く」を押すと開くが、条件（日付・エリアなど）が効いていない | そのサイトの検索ページのURLの形が変わった | 下の「F」 |

画面の「くわしく」を開くと、楽天から返ってきた原文（例: `HTTP 403 …`）が見られる。直すときの手がかりになる。

## A. キー・許可するWebサイト
1. https://webservice.rakuten.co.jp/ にログインし、アプリの設定を開く
2. 「Application ID」と「Access Key」をコピーし直し、アプリの「設定」→「楽天GORAの空き確認」に貼り付けて「保存する」→「接続を試す」
3. 「Allowed websites（許可するWebサイト）」に `wata98.github.io` が入っているか確かめる
4. 楽天は、アプリの「再登録」を求めることがある（2026年2月に実際にあった）。楽天からのメールを確かめる

## B. 503（メンテナンス中か混み合っている）が続く
- 楽天のサイト（webservice.rakuten.co.jp）のお知らせを見る
- **パソコンの `localhost` で開いているときは、楽天は 503 を返す**（2026-11-09 に確かめた）。空き確認は公開サイト（https://wata98.github.io/golf-app/）で試す

## C. 楽天のAPIの住所・版が変わった
- `js/features/availability/gora-api.js` の `API_URL` を直す
- 今の値: `https://openapi.rakuten.co.jp/engine/api/Gora/GoraPlanSearch/20170623`
- 新しい値は、楽天ウェブサービスの「楽天GORAプラン検索API」のページの「リクエストURL」に書いてある
- 版（最後の数字）が変わると、条件の名前や返事の形も変わることがある。ページの「入力パラメーター」「出力パラメーター」と、`buildRequest`（条件の作り方）・`parseResponse`（返事の読み方）を見比べる
- 直したら `tests/availability.test.js` の見本も新しい形に合わせて、テストを通す

## D. 返事の形が変わった
- エラーに「〇〇がありません」と出た項目名を、楽天のページの「出力パラメーター」で探し、新しい名前に `gora-api.js` の `parseResponse` を直す
- 今読んでいる主な項目: `Items` / `golfCourseName` / `planInfo` / `planName` / `price` / `playerNumMin` / `playerNumMax` / `startTimeZone` / `assu2sum` / `calInfo` / `stockStatus` / `reservePageUrlMobile`

## E. ブラウザから呼べなくなった
- 楽天が「ブラウザからの直接の呼び出し」をやめた場合（返事に `Access-Control-Allow-Origin` が付かなくなった場合）、サーバーなしでは呼べない
- その場合は空き確認の一覧をあきらめ、「各サイトを条件入りで開く」ボタンだけで使う（キーを消せば、自動でその表示になる）
- 無料の中継サーバーを使う方法もあるが、登録が増え、無料枠を超えたときに課金されないかを確かめる必要がある（CLAUDE.md の「月額・従量課金が一切かからない」に合うか）

## F. 各サイトの検索ページのURLの形が変わった
- 直すのは `js/features/availability/site-links.js` だけ
- 直し方:
  1. そのサイトの1人予約（または通常の検索）のページを開き、条件（日付・エリア・時間帯・予算）を選んで検索する
  2. 検索結果のページのアドレス（URL）をコピーする
  3. ファイルの先頭のコメントにある「確かめた形」と見比べ、名前が変わったところ（例: `region[]` → `pref[]`）を直す
  4. コメントの「確かめた形」と日付も新しくする
  5. `tests/availability.test.js` の「各サイトのURL」のテストも直して通す
- 2026-11-09 に確かめた形:
  - 楽天GORA（通常・1人予約）: `month` / `day` / `widthday`（日数）/ `area[]`（エリア番号 8茨城〜14神奈川）/ `zone_list[]`（6〜11）/ `rates_max`（5000, 8000, 10000, 13000, 15000, 20000 のどれか）。1人予約は `menu=srch_solo`
  - GDO 1人予約: `dp`（日付）/ `during`（1, 3, 5…）/ `region[]`（都県名。例 千葉県）/ `start_time[]`（6〜12）/ `price_upper`（5000〜20000 の1000円きざみ）/ `unfull=1`（満員を除く）
